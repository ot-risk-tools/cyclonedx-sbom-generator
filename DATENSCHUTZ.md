**Kurz gesagt: Deine Eingaben verlassen dein Gerät nicht.**

## Was das Programm mit deinen Eingaben macht

- **Keine Übertragung.** Das Programm läuft vollständig in deinem Browser. Es sendet keine Eingaben an einen Server, weder an den Betreiber dieser Seite noch an Dritte.
- **Technisch abgesichert.** Die Seite enthält eine Content Security Policy mit `connect-src 'none'`. Der Browser blockiert damit Netzwerkverbindungen des Programms.
- **Speicherung nur lokal.** Die Eingaben werden im Speicher deines Browsers (localStorage) abgelegt, damit sie nach dem Schließen noch da sind. Sie sind dort unverschlüsselt. *Neu beginnen* löscht sie; das Löschen der Browserdaten ebenfalls.
- **Dateien bleiben lokal.** Wählst du eine Datei für die Prüfsumme aus oder öffnest du eine Stückliste, wird sie nur auf deinem Gerät gelesen und nicht hochgeladen.
- **Keine Cookies, keine Analyse, keine Werbung.** Das Programm lädt keine Schriften, Skripte oder Bilder von Dritten.

## Hosting über GitHub Pages

Die Seite wird über GitHub Pages ausgeliefert (GitHub, Inc., USA). Wie jeder Webserver verarbeitet GitHub beim Abruf der Seite technische Daten, etwa die IP-Adresse, den Zeitpunkt und Angaben zum Browser. Darauf hat der Betreiber dieser Seite keinen Einfluss und keinen Zugriff. Näheres steht in der Datenschutzerklärung von GitHub: https://docs.github.com/de/site-policy/privacy-policies/github-general-privacy-statement

Wer das vermeiden möchte, lädt das Programm als ZIP-Datei herunter und öffnet die Datei `index.html` direkt. Dann findet beim Arbeiten kein Abruf mehr statt.

# Privacy and legal notes

**In short: what you enter does not leave your device.**

## What the program does with your entries

- **No transmission.** The program runs entirely in your browser. It sends nothing you enter to a server, neither to the operator of this page nor to third parties.
- **Technically enforced.** The page carries a Content Security Policy with `connect-src 'none'`. The browser therefore blocks network connections made by the program.
- **Local storage only.** Your entries are kept in your browser's storage (localStorage) so they are still there after closing. They are stored unencrypted. *Start over* deletes them, and so does clearing your browser data.
- **Files stay local.** When you pick a file for the checksum or open an SBOM, it is only read on your device and not uploaded.
- **No cookies, no analytics, no advertising.** The program loads no fonts, scripts or images from third parties.

## Hosting on GitHub Pages

The page is delivered through GitHub Pages (GitHub, Inc., USA). Like any web server, GitHub processes technical data when the page is requested, such as the IP address, the time and details about the browser. The operator of this page has no influence on that and no access to it. See GitHub's privacy statement: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

To avoid this, download the program as a ZIP file and open `index.html` directly. No request is made while you work.

## The generated file

An SBOM can be confidential because it shows which software a product contains. It also contains the contact details you enter (name, email address). Pass the file only to recipients who are meant to have it.
